# Project context

Living context for the AI Assistant concept (MedTech, industrial side).
The source of truth for decisions is kept in the Claude Project "Design Challenge"
(`claude/contexto-design-challenge.md`). Stage artifacts (03+) are added to this folder as `.md`.

- Scope: industrial MedTech (medical disposables manufacturing), not clinical users.
- Persona: proto-persona from desk research; a synthetic persona is used only as a tool to stress-test hypotheses, never as evidence.
- Process: structure first, built directly in code with the design system in grayscale (wireframes), then themed (high fidelity).
- Design system: Astryx (Meta, open source), Neutral theme, as a dependency.
- Hosting: Vercel, connected to this repo.
